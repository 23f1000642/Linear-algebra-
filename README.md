# Linear Algebra – GATE DA

A React component for practicing linear algebra concepts relevant to GATE DA (Data Science & AI), including row reduction (RREF), null space basis computation, and related matrix operations, with step-by-step solution logs.

## Contents

- [`linear-algebra-gate-da.jsx`](./linear-algebra-gate-da.jsx) — the main component.

## Usage

This component depends on `react` and `lucide-react`. Drop it into a React project (e.g. Vite or Create React App) that has those installed, and render the exported component.
